Lumi's font: Nunito (variable weight), from Google Fonts (github.com/google/fonts, ofl/nunito).
Nunito-Variable.ttf is the file "Nunito[wght].ttf", renamed. It is under the SIL Open Font License (OFL.txt),
so it can be included in a free or paid app. Every screen, sign and label in Lumi uses this one font.
