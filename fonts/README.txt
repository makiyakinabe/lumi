Put Lumi's font here (one file):

  Nunito-Variable.ttf   (or Nunito-Variable.woff2)

Get it free from https://fonts.google.com/specimen/Nunito -> "Get font" -> "Download all".
In the zip, take "Nunito-VariableFont_wght.ttf" and rename it to "Nunito-Variable.ttf".
Nunito is under the SIL Open Font License, so it can be included in a free (or paid) app.
Keep the OFL.txt licence file from the zip in this folder too.

Without this file Lumi still works: it uses the tablet's own rounded font.
